# System Monitoring Script (Cloud Deployment)

Python-based script to monitor website availability and log system status.

## Features
- Checks website status (UP/DOWN)
- Logs results with timestamps
- Runs continuously every 10 seconds
- Deployed on AWS EC2 instance

## Technologies
- Python
- Requests
- AWS EC2 (Ubuntu Linux)

## Deployment
This script was deployed and executed on an AWS EC2 Linux instance, simulating a real-world monitoring environment.

## Purpose
Demonstrates system monitoring, automation, and hands-on cloud deployment experience.
